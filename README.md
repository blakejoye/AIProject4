## Setup Instructions
1. Install dependencies:
   pip install torch torchvision scikit-learn matplotlib numpy

2. Run each task individually using the provided scripts:

### Task 1: PCA
    python task1_pca.py

### Task 2: 1-Layer Autoencoder
    python task2_autoencoder_1layer.py

### Task 3: Deep Autoencoder with Activation Comparison
    python task3_autoencoder_deep.py

    OR if using pycharm simply hit the run button for each

Each script will display visualizations and print reconstruction losses.
